# Admin Dashboard Project

A basic dashboard project built to practice page layout using with Flexbox 
and CSS Grid.

## Technology used

- HTML5
- CSS3
- VS code
- Git

## About the project

The goal of this project was to practice building and styling a dashboard
layout using a combination of Flexbox and CSS Grid.

The project focuses on creating a structured layout while improving my understanding of how
Flexbox and Grid can be used together to build modern web interfaces.

## What I practiced

- Building page layout with CSS Grid
- Using Flexbox for smaller layout components
- Combining Grid and Flexbox in the same project
- Structuring a multi-section dashboard
